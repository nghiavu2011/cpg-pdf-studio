💻 Bản Portable Desktop Dành Cho Windows

Hệ thống CPG PDF Studio cung cấp 2 phương thức sử dụng linh hoạt:

1. Bản Web Trực Tuyến / Cục Bộ (Vercel & Local):
Chạy trên mọi trình duyệt hiện đại (Chrome, Edge, Firefox) thông qua WebAssembly, hoàn toàn bảo mật cục bộ, không gửi dữ liệu ra ngoài.
2. Bản Native Executable (.exe) Portable:
Được viết bằng Rust thuần túy, đặt trong thư mục portable/pdfcraft-0.6.0-windows-x64-portable/pdfcraft.exe. Không cần cài đặt, chỉ cần click file Start-CPG-PDF-Native.bat là mở ngay lập tức!
ℹ️ Phím Tắt & Tính Năng Chuyên Nghiệp
Phím Tắt Chức Năng
Ctrl + K Mở Command Palette (Toàn bộ công cụ chỉnh sửa)
Ctrl + O Mở tệp PDF mới
Ctrl + S Lưu và tải về tài liệu đã biên tập
Ctrl + Z / Ctrl + Y Hoàn tác (Undo) và Làm lại (Redo) không giới hạn
Ctrl + F Tìm kiếm từ khóa trong tài liệu
Alt + Drag Chọn văn bản theo cột (Column Select)
